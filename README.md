# 未来漫境 Windows 便携版

版本：1.0.1.1122

启动：双击 未来漫境.exe。无需安装，也不创建桌面快捷方式。

PC 与安卓版使用相同的产品名、漫画封面图标和“未来不是未来”创作者署名，并包含相同的核心功能：
- 漫画下载与连续阅读
- 本地阅读：扫描漫画目录、列出图片文件，支持名称搜索；图片按每组 16 张载入，避免一次性解码整个目录
- 图片混淆 / 解混淆：Gilbert 曲线与黄金比例偏移，轮数 1–10，带进度条，可恢复当前载入原图
- 图片隐藏 ZIP：把 ZIP 附加到 JPG 或 PNG 末尾；这是伪装，不是加密，不提供提取入口
- 光棱工厂：打开随程序提供的离线页面，在默认浏览器中使用

图片混淆会把超过 800 万像素或长边 4000 px 的图片缩小到处理上限。PNG 输出便于保持可逆所需的像素。

漫画内容保存在程序旁边的 JMD 文件夹。请将程序放到具有写入权限的位置；升级时保留 JMD 文件夹即可保留下载内容。
第三方组件许可见同目录的 THIRD_PARTY_NOTICES.txt 与 LICENSE-*.txt。
